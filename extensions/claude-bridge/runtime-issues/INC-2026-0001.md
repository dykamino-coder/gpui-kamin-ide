# INC-2026-0001 — CEF software-render CPU field diagnostics

- **Status:** investigation
- **Diagnostic PR:** public PR #25 was closed unmerged after privacy review
- **Fix PR:** none
- **Private evidence:** [INC-2026-0001](https://github.com/dykamino-coder/gpui-kamin-ide-priv-evidence/tree/main/incidents/INC-2026-0001)
- **Dependencies:** none
- **Acceptance:** source audit + automated tests + Windows runtime measurement
- **Corporate observation owner:** none

## Symptom

Полевой diagnostic bundle был собран для исследования высокой CPU-нагрузки и
software-render поведения CEF views. Первоначальная public diagnostic branch
содержала raw corporate data и поэтому не была смержена.

## Confirmed facts

- Сохранены bounded CPU, thread, module, environment, crash, CEF и host
  snapshots одного наблюдения.
- Private bundle содержит авторский анализ software-render throttling и hidden
  webview state с attribution исходному исследователю.
- Functional fix в рамках исходного diagnostic PR не выполнялся.

## Hypotheses

- replay cache мог не использоваться в наблюдаемом сценарии;
- полный buffer copy мог выполняться при существенно меньшем dirty region;
- `TS_PROCESS_CRASHED` / `STATUS_BREAKPOINT` требуют отдельной корреляции с
  renderer lifecycle.

Ни один пункт пока не считается доказанной единственной причиной.

## Expected outcome

Maintainer сверяет private evidence с актуальным `origin/main`, локализует
нарушенный контракт либо фиксирует недостающие measurements. Любой functional
fix оформляется Change/Fix PR с automated tests и Windows runtime gate.

## Privacy cleanup

После merge private evidence PR #1 и проверки checksums удалить remote branch
`docs/diagnostics-2026-09-01`. Поскольку закрытый public PR #25 и его internal
pull refs могут сохраняться вне обычных branch refs, владелец отдельно запрашивает
у GitHub Support удаление cached diff/PR refs; переписывать `main` не требуется.
