## Symptom

`cargo html-test --features wpt-harness` stops with `STATUS_STACK_OVERFLOW` (exit `0xC00000FD`, `3221225725`) in
`depth_tests::special::inline_grid_math_table_and_multicol_paint_at_browser_depth_on_eight_mib`.
The process dies, so every test after it in the suite is not run. Agents therefore cannot get a complete local HTML suite result.

## Confirmed facts

- Reproduced on exact `origin/main` `636f3f5f` in a clean detached worktree. The test binary's PE stack reserve is 8,388,608 bytes. The source code was not modified.
- The same test overflows on a branch whose production `crates/html/src` is byte-identical to `origin/main`, so it is not caused by that branch.
- The test was added by #430 (`bb944577`). It paints documents nested 1026 levels deep for `inline`, `grid`, `math`, `table` and `multicol` inside `regression::on_eight_mib` (`crates/html/src/depth_tests/special.rs:59`).
- `cargo html-test` is defined in `.cargo/config.toml` as `test -p kamin-html --lib --profile agent`. The `agent` profile builds `kamin-html` with `opt-level = 0` (`Cargo.toml`, `[profile.agent]`).
- CI runs `cargo test --workspace` in the `dev`/`test` profile, where `kamin-html` has `opt-level = 2`. The Windows Rust tests pass there on `main`, so CI does not see this failure.
- In the same agent-profile run, other depth tests pass, for example `depth_tests::limit::beyond_box_limit_paints_the_remainder_and_keeps_the_whole_dom`.

## Fragment frame reduction (2026-10-31)

- Move fragment geometry/layout/background preparation into helpers that return before recursive content traversal; keep sliced paint state on its own branch. Borrow prepared replay routes instead of moving the large value between stack slots. No new heap allocation or per-kind depth exception is introduced.
- Compiler-confirmed opt-level 0 owner frames: `prepaint_frags` 1520 → 864 bytes, `paint_frags` 2080 → 784 bytes. New preparation helpers use 1200/1088 bytes but return before ordinary content recursion; sliced paint uses a separate 432-byte frame.
- Actual recurring multicol chain: prepaint 8256 → 7728 bytes per source level; paint 7728 → 6432. At 1026 levels this projects to 7,928,928/6,599,232 bytes before fixed setup. All 35 isolated kind/phase endpoints pass on the existing 8 MiB stack at opt-level 0.
- Agent per-level request/layout/prepaint/paint bytes for the unchanged paths: block 3008/4000/2640/2512; inline 0/0/0/0; float 7360/7216/6816/7680; grid 3008/6224/2640/2512; math 0/0/0/0; table 3008/4236/2640/2512. Inline/math flatten source nesting; table has one table per four source levels. Multicol lazy construction runs inside prepaint, so request/layout invocation envelopes also fall from 8256 to 7728; its build envelope remains 5984.
- The full `cargo html-test --features wpt-harness` agent suite completes: 2081 passed, 0 failed, 3 existing ignored, 0 filtered out. Required all-targets wpt-harness clippy passes with `-D warnings`.
- Tests, stack sizes, profiles, depth limits and shared scripts are unchanged. Dev suites, opt-level 2 comparison, release timings and RGB acceptance remain pending; the lead owns PR creation and merge.
