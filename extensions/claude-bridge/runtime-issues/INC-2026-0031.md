## Source countercheck

At the intake baseline, webview/src/components/widgets/QueueWidget.tsx uses activeLocalQueue and its Send now handler calls interruptSession. It intentionally does not resend the queued text. Therefore the owner's possible resend/duplication concern must be tested, not recorded as a confirmed duplicate-send defect. Removing an item here also changes the local display map; do not assume this cancels CLI input.
