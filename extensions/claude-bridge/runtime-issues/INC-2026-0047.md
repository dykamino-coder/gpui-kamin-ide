## Source-trace follow-up — 2026-11-13 (cxstats)

Source baseline: `32109f31cd9a4940726d216e5deae03aef1220d5`, compared with
`origin/main` `848ac4618d81dad519958060fccb7200489bc5d9`. Git ancestry and the
merged PR record confirm #702's merge commit above is already in main. No
test, CLI rewind, build or native acceptance was rerun under HOLD-PAIRS.

`webview/src/components/jsonl-viewer/compute-chain-uuids.ts` no longer takes
an unqualified union of every leaf. `abandonedBranches` takes the last
non-sidechain user/assistant record in entry order as its tip, walks that
ancestry, and removes sibling real-prompt subtrees.
Non-prompt forks retain multi-tip behavior, streaming stubs do not seed the
walk, and intentionally abandoned users are excluded from the missing-user
safety net. Preserve those distinctions instead of replacing the predicate
with a blanket single-leaf filter.

Existing `signals/chat-render-matrix.test.ts` covers the D4 abandoned branch,
rewind to the root, repeated rewinds delivered in pages, and a hook-attachment
fork. `chat-render-property.test.ts` includes rewind schedules for 60 seeds.
#702 records old-code failures for rewind cases and 22 property seeds; those
are that PR's historical results, not new execution here. Its stated boundary
is a shown segment: rewind across compaction was not covered. Its automated
predicate acceptance does not replace this incident's native Chat/Console gate.

The watcher also already detects shrink, changed file identity, and equal-size
rewrite with changed mtime (`pty/jsonl-watcher.ts::poll`). File replacement and
