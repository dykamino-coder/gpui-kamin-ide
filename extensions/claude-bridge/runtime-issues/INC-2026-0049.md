## Symptom and scope decision

The owner could not find how to obtain a session folder/reference for passing
an ID to Bridge. The old note does not distinguish copying directory contents
from copying its path or identifier. Scope the first deliverable to obtaining
the correct reference for a selected session; do not implement export of the
folder or invent a new import/migration operation from this ambiguous note.
