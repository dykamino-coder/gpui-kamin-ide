# INC-2026-0149 — Keep the Stop button tied to the active turn

- **Status:** confirmed
- **Registration author:** @dvpetrochenko
- **Completion target:** ship the fix and verify the field observation after deployment.
- **Acceptance:** automated merge gate on a synthetic fixture, followed by deployment observation.
- **Private evidence:** not required for reproduction. Use the fixture in this change.

## Source finding

The composer included a host-wide MCP readiness flag in its turn-busy predicate. During an outstanding readiness query a connected, idle tab with an empty input displayed Stop even after its engine had reported completion.

## Acceptance

With the MCP readiness query pending, a running turn shows Stop. After the session activity event changes to idle and prompt-ready the button becomes Send. A subsequent turn restores Stop. Verify final text alone leaves a still-running turn interruptible.
