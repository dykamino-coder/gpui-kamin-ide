## Symptom

При нескольких открытых sessions Console периодически сериализует snapshots
даже неизменённых неактивных terminals. Каждое такое сохранение передаёт весь
общий snapshot map. Закрытые tabs остаются в map, а native document recreation
не восстанавливает эту state через текущий CEF shim. Получается повторная
фоновая работа без заявленной durable restore гарантии.

## Confirmed facts

1. `extensions/claude-bridge/webview/src/components/terminal/TerminalPanel.tsx:69`
   монтирует terminal каждого tab. `TerminalContainer.tsx:18/45` в той же папке
   вызывает useTerminal и для inactive tab; тот скрывается только display:none.
2. `extensions/claude-bridge/webview/src/hooks/useTerminal.ts:409–421` каждые
   10000 ms вызывает serialize и storage.setItem без dirty/visibility guard.
   Cleanup на строках 435–442 записывает последний snapshot. Close path не
   удаляет его key; explicit reconnect reset удаляет лишь свой key в
   `extensions/claude-bridge/webview/src/signals/terminal-registry.ts:42`.
3. `extensions/claude-bridge/webview/src/lib/storage.ts:20–31` при каждом
   setItem сохраняет весь mem без equality check. Actual-source synthetic
   cycle из 10 unchanged ASCII snapshots по 262144 characters создал 10
   payloads и 26217730 JSON bytes при 2621440 bytes суммарного содержимого.
   Код ограничивает `data.length`, то есть UTF-16 code units, не UTF-8 bytes;
   соответствие characters=bytes относится только к synthetic ASCII payload.
4. `crates/shell/src/ui/chat_webview.rs:150–154` JSON-stringifies state и
   отправляет POST `/__ipc`. Строки 88–99 создают thread, разбирают JSON и
   отбрасывают `__kaminState`: persistence для этого пути не реализован.
   getState остаётся document-local; после уничтожения/recreation document
   эти snapshots не восстанавливаются через данный native путь.

## Hypotheses

Не измерены actual CPU%, heap, wire throughput или Windows latency. Synthetic
число bytes доказывает повторное full-map serialization при заданном payload,
а не типичный production объём. Hidden-page throttling может менять частоту
таймеров. Inactive xterm buffers могут быть нужны для быстрого switch;
обязательное уничтожение всех background terminals не предлагается.
Resize hook уже проверяет visibility, а terminal cleanup выключает timer и
dispose renderer: это не orphan interval после unmount. PTY redraw/replay
может показать актуальный экран после reconnect, но не сохраняет прежний
scrollback snapshot через document recreation. Причина INC-0001/OOM этим
исследованием не установлена.

## Expected outcome

Bounded Change/Fix PR сначала фиксирует snapshot lifetime contract: panel
switch, CEF recreation и app restart. Реализация должна избегать повторной
сериализации unchanged tabs и полного multi-tab map на каждый per-tab tick,
ограничивать closed-tab retention и обеспечивать выбранный restore contract.
Согласовать native persistence изменения с отдельной lifecycle работой.

Automated acceptance измеряет serializer calls, retained keys и payload bytes
для idle/dirty tabs, batching, close/reconnect, Unicode и document recreation.
Windows CEF gate: 1/5/10/30 tabs, idle/streaming, hidden Console, switch return,
close, manual reconnect и reap/reveal. Проверяются responsiveness, память,
сохранность предусмотренного scrollback и корректность актуального экрана.
Обещание performance improvement допускается только после этих измерений.
