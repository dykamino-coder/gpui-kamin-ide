## Reported symptom and verified source findings

The owner reports intermittent hangs of local Read/Write/Edit/Glob/Grep/Bash.
The suspected socket cause remains unconfirmed. Controlled tests established:

- A result above the extension's 4 MiB serialized-frame budget was rejected
  locally without a correlated answer; the server could wait its 30-minute
  heavy-tool deadline. The fix returns a compact acknowledged tool error.
- A request refused by a full server send buffer was retried only on reconnect.
  The fix retries after drain, stops on admission and immediately rejects a
  request that can never fit the 16 MiB frame budget.
- A foreground shell deadline could wait indefinitely for `close` when a
  descendant retained inherited pipes. The fix settles after bounded termination
  grace and clears owned timers/pipes independently of that event.

These are reproducible source defects, not proof of the owner's historical
failure. Results that report size failure may follow successful side effects;
inspect effects before retrying Write/Edit/Bash.

## Remaining contracts and exact next evidence

The following ordinary-request limitations predate MCP Tasks. Modern Bash/
PowerShell Tasks separately use `tasks/cancel`, deadline cancellation and a
24-hour owner-bound client result outbox across PTY replacement. That outbox is
still memory-only and bounded at 64 outcomes; no native crash-recovery guarantee
is added by the server retention fix. Ordinary overload fallback keeps the
ordinary-request semantics below.

HTTP stream disconnect intentionally preserves ongoing side-effecting work.
`notifications/cancelled` currently acknowledges without cancelling execution;
server deadlines do not send a client execution-cancel message. Changing this
requires an explicit cancellation/terminal-outcome contract, rather than blindly
cancelling work on an SSE disconnect.

Accepted requests have no client receipt ACK. Loss after transport admission,
client crash, outages beyond the existing 120-second retention and more than
64 retained outcomes remain outside the controlled delivery guarantee. Replaying
an admitted Write/Edit/Bash could repeat its effects. Heartbeats establish socket
liveness, not tool execution progress. Windows process-tree termination cannot
guarantee removal of already orphaned descendants. Do not mark this incident
resolved solely from the controlled tests.

For the next occurrence, lead enables `KAMIN_BRIDGE_MCP_DIAGNOSTICS=1` in the
extension-host launch environment. Collect a bounded interval of opt-in stage,
request/session ID, timestamp and queue-byte/count metadata plus matching server
send/admission/response metadata, disconnect timing and exact versions. Review
and redact before private intake; exclude arguments, output, environment values
and credentials. Match the last completed stage to local execution, request
receipt or return delivery. If needed, add numeric bufferedAmount, heartbeat age
or process-exit metadata only at the implicated stage. Full investigation and
limitations are in the immutable private packet.
