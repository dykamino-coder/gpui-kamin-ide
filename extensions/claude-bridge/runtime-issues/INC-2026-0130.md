## Confirmed facts

At baseline `2212d6e14d701b3184a200cd742413667175ad08`, terminal output is held
for an 8 ms trailing debounce or 32 ms maximum wait. The PTY exit handler sends
the exit frame and closes the socket without flushing that buffer. Thus a
diagnostic emitted immediately before exit can disappear for either engine.

## Resolution and limits

Flush before the exit frame, cancel both timers even for a closed socket and
clear the buffer regardless of socket state. Disconnect discards the buffer;
late output cannot restart timers. Exit handling is idempotent, and closing
the socket after exit no longer tries to kill the dead PTY. A disconnect or
kill request still does not release the Codex account lease: only process exit
does so, retaining the existing exclusive CODEX_HOME contract.

This guarantees ordering for data already delivered by node-pty to the server;
it does not recover output that the CLI never wrote or node-pty never emitted.
Local macOS tests do not establish the corporate deployment outcome or live
Windows behavior. No credentials, certificates or subscriptions are used.
