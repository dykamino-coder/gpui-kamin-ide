# INC-2026-0150 — Retain transport diagnoses in workspace WebFetch failures

- **Status:** confirmed
- **Registration author:** @dvpetrochenko
- **Completion target:** ship the fix and verify the field observation after deployment.
- **Acceptance:** automated merge gate on a synthetic fixture, followed by deployment observation.
- **Private evidence:** not required for reproduction. Use the fixture in this change.

## Source finding

Node fetch commonly throws an outer TypeError with a generic message. The workspace tool returned that message while discarding its nested transport code, obscuring DNS, TLS, timeout and connection failures.

## Acceptance

A successful public fixture returns its body. A received HTTP status remains visible. A known nested transport failure exposes its classified code without serializing the underlying peer message. Unknown failures use the existing fallback.
