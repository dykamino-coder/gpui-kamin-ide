## Symptom and scope

At display scale 1.25, a specified 1 CSS px border remains 1 CSS px in
the engine. Chromium uses 0.8 CSS px, corresponding to one device pixel.
The additional 0.4 CSS px per pair of edges changes flex/grid space
distribution and accumulates in nested intrinsic sizing. Three measured
examples share this discrepancy; the rest of the comparison class remains
unmeasured. The initial flex-basis hypothesis was disproved by geometry.

CSS Backgrounds 3 requires computed border widths to be snapped as border
widths. CSS Values 4 preserves integral device-pixel lengths, promotes a
positive subpixel width to one device pixel, and truncates larger widths.
Resolve this once after relative lengths and zoom, before publishing style,
so layout and all painters read the same value. Preserve cascaded lengths
for recomputation after mutations or a display-scale change.
