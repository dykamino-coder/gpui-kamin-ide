## Symptom and acceptance

At the per-token session limit, the input identified the refusal while Console kept connecting and the engine selectors offered unresolved choices. The waiting state must show the refusal in chat and Console, retain drafts, withhold the engine controls and restore them automatically on admission. Test the transition with a synthetic tab and the same status used by the host.

After admission the server used to query ChatGPT plan windows only when a turn finished. Publish the account snapshot on admission, reattach, wake and engine switch. Accept a reported percentage with an unknown reset date. An account that supplies no windows still has no percentage to show.

Administrators can choose an initial effort across new chats with `BRIDGE_CODEX_DEFAULT_EFFORT`. Accept a configured level only when the selected model advertises it. Preserve explicit choices and restored threads. Check the accepted first turn over the Bridge WebSocket with a model supporting the configured default and the fallback on a restricted model.
