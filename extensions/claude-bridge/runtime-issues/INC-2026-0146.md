## Source finding

Claude discovers skill overlays and enabled plugin snapshots in its own CLI. A Codex thread receives synced user and project instruction files but starts in a Bridge-owned working directory. Native plugin and skill search are restricted in the shared app-server. The client's installed skills had no equivalent discovery path in Codex.

## Acceptance

A capable client advertises a catalog for its authenticated Codex session. Listing uses the calling connection's project and returns source, description and the entry point on the client. The agent uses the ordinary permission-checked Read tool to retrieve the instructions. Check project precedence, cross-project isolation, model invocation restrictions, plugin disable/update, and the existing Claude path. Test the complete discovery and read sequence before checking model behavior at the deployment. Skills with engine-specific execution or permission semantics require their native runtime.

The catalog skips dependency and Git trees below a declared root and flags truncated scans. A project override or opt-out takes precedence by directory and declared skill name.
