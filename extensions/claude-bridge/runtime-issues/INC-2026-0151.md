## Source finding

When a stdio connector exited before initialization, the manager's generic exit handler replaced the transport's missing-module diagnosis. Discovery then discarded that diagnosis and launched the same broken connector again.

## Acceptance

A missing fixture module leaves a visible reason and no automatic retry on unchanged discovery. Explicit Test or a changed configuration permits a new attempt. A generic exit code 1 uses bounded backoff and stops.
