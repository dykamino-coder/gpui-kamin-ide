## Symptom and cause

Repeated full mutation rebuilds can eventually reject a document for exceeding
the revision CSS-declaration limit even when each edited document fits that
same limit when built fresh.

`Document::apply` creates a candidate revision budget, but the retained
`Admitted` input still carries its preceding context when the full rebuild
starts. Source admission and conversion derive their budget from that context.
Repeated source admission therefore charges an earlier revision's ledger.

Move the retained input into the candidate context before source admission,
sharing the existing live-DOM counters. If the candidate is rejected, restore
the committed input context and agent CSS costs with the existing mutation
rollback. The CSS limit and work-counter contract remain unchanged.
