## Confirmed behavior

A resumed thread can contain an initial model line with one effort and a later Bridge context with another. The console and normalized transcript report reasoning activity and usage. Neither records the effort on the accepted turn/start request. The historical inference setting cannot be reconstructed from a model answer, token count or latency.

## Reproduction and acceptance

Resume a synthetic thread on Low. Select Extra high and start the next turn. Correlate its RPC effort with a structured transcript entry and a visible console indication. A steer must not receive a second turn-start receipt. A rejected request must not acquire an accepted receipt. An omitted field must be distinguishable from an explicit level.
