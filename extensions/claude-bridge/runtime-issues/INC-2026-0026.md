## Symptom

Bridge samples and connection transitions are split between retained incident.log
generations. Each file contains an invalid JSONL fragment. The defect now has
both an actual-module synthetic reproduction and three owner-supplied field examples.

## Confirmed facts

- Source `365a56ade9915811b2034cc205ac7eea11ae466e`:
  `extensions/claude-bridge/extension/src/incident-diagnostics.ts:124–125`
  sends complete formatted incident lines through `RollingLogWriter.write`.
  Samples and transitions use that emitter. Installation at lines 155–169
  sets a 1 MiB cap, three backups and rotation on open.
- `src/kamin-host/rolling-log.ts:107–132` fills the remaining bytes before
  rotating. Unlike `writeRecord:81–105`, that raw-stream API does not preserve
  structured boundaries. The tracked bundled extension uses the same `.write`.
  These production files are unchanged from the original a34ab48 audit.
- The earlier harness used the real writer/extension module at the production
  cap: 80 bytes of remaining capacity split a 314-byte sample into 80 and 234.
  Neither fragment parsed individually; concatenating them restored the record.
- Newly supplied field generations show three exact byte splits, excluding LF:
  13+299 (.3→.2), 207+105 (.2→.1), 199+36 (.1→current). The first two are samples,
  the last a connection transition. Joining original generations reconstructs
  three more complete records: 12,058 rather than 12,055 from independent files.
  Only an incomplete oldest prefix remains, requiring an older unavailable
  generation. Original files and hashes are preserved privately in INC-2026-0020.

## Counterchecks and scope

BR-30's record-aware API and migrated host emitter still have valid host
filesystem acceptance. The extension bypasses that path, leaving the all-emitters
expectation in `RUNTIME_RELIABILITY.md:1391–1396` incomplete. Existing extension
diagnostic tests do not exercise real rotation files. The host's startup-only
`data/incident.log` is separate from the extension globalStorage trail.

Field splits occurred at 2026-09-06 19:34:20.612, 2026-09-07 02:17:35.624 and
09:01:44.469 UTC. None overlaps the 07:53–07:57 CEF sample gap. This confirms
record corruption without attributing the renderer crash or sample gap to rotation.
No Windows filesystem run or functional fix is included in this Diagnostic PR.

## Expected outcome

Route the extension's structured emitter through the record-aware contract,
define bounded handling of oversized records, and regenerate its shipped bundle.
Preserve raw host.log behavior and retention limits. Test the actual extension
emitter for samples/transitions, ASCII/UTF-8 boundaries, restart and independently
parseable retained generations. Run the filesystem gate on Windows; GUI access
is unnecessary for this acceptance.

Keep the incident open until a separately authorized Change/Fix PR implements
and verifies the complete path. No registry change, version bump or release.
