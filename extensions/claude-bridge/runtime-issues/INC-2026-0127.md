# INC-2026-0127 — `/compact` in a GPT (Codex) chat is sent to the model as text

- **Status:** confirmed
- **Registration author:** `kacc22`, Bridge executor, lead-directed (2026-11-19). Found by `kacc21` during the #1047 live gate; listed as a known limitation of 1.0.117 ([#1055](https://github.com/dykamino-coder/gpui-kamin-ide/pull/1055)).
- **Completion target:** `/compact` in a Codex chat compacts the thread (as automatic compaction already does) instead of reaching the model as a prompt.
- **Diagnostic PR:** this registration.
- **Fix PR:** none
- **Next step:** change. Map `/compact` in Codex tabs to the app-server's thread compaction request and show its result in the chat. Owner: next Bridge executor.
- **Private evidence:** not required.
- **Dependencies:** none.
- **Acceptance:** an automated test of the command mapping, plus one live run: a Codex chat, `/compact`, the thread compacts, the next turn keeps the context.

- **Deployment observation owner:** the executor of the fix.

## Symptom

Typing `/compact` in a GPT (Codex) chat sends the text `/compact` to the model, which answers it as a message. Bridge has no manual compaction for Codex chats.

## Confirmed facts

- Automatic compaction of Codex threads works (forced in the #1047 gate: the thread compacted and kept its memory).
- Manual `/compact` is handled for Claude chats only.
