## Confirmed behavior

The session WebSocket handler applies the external tool snapshot after createSession returns. A Codex app-server that lists tools during thread/start sees the built-in tools but misses the submitted external tool. A later tools/list and call succeed. A cold resume takes the same admission path. The Codex session also initializes its registries empty during an engine switch.

## Reproduction and acceptance

Using a synthetic connector, check that the first tools/list already includes its tool on create and cold resume. An engine switch must carry the originating chat's registrations. Keep the live notification and token isolation tests.
