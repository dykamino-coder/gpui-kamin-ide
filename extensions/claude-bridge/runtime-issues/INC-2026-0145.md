## Symptom and cause

Claude uses its native CLI hook relay. Codex workspace operations reach the client through Bridge MCP. Its endpoint previously forwarded these operations without evaluating the authenticated workspace's tool hooks. Active Hooks reports registered handlers, so a populated list alone cannot establish enforcement.

## Verification

Start a chat with an approved fixture command. On its first call, an allowed read reaches the host once. A denied read stops before host dispatch. Check post-success and post-failure events, resource reads, and a server-owned project tool. Repeat with a distinct user, a second project, a legacy client and a session that has no hooks. Verify that editing or revoking the local approval affects subsequent calls, and that a failed, cancelled or timed-out matching guard cannot authorize execution.

The matching inputs are the client's user settings, project settings and enabled, approved plugin snapshot. An applicable project-only handler and unsupported host or decision return an explicit diagnostic. Native Claude retains its CLI dispatch. Workspace tool hook behavior and the Active Hooks display in INC-2026-0138 have separate acceptance checks.
