## Symptom

In a newly started chat, the first task begins agent work. A second prompt sent
immediately afterward appears as pasted text in Console but is not submitted;
no pending item appears in Message Queue. The owner suspected association with
launching another agent but did not compare the same timing without agents.

## Checked source and limits

At `14a154b477c92cee5905db6d0e951126a10fb408`, [extensions/claude-bridge/webview/src/lib/send-message.ts](https://github.com/dykamino-coder/gpui-kamin-ide/blob/14a154b477c92cee5905db6d0e951126a10fb408/extensions/claude-bridge/webview/src/lib/send-message.ts)
computes busy from `isWorking || !promptReady`, conditionally calls
`enqueueLocal`, clears prompt readiness and always calls `submitText`.
The queue is a visual mirror; CLI owns actual queued input. This establishes
where the contracts meet, not why the historical input remained unsubmitted.
The serialized submit introduced in PR #5 is not proof that this precise
new-session/agent-start timing was accepted in a real CLI.

## Research deliverable and expected outcome

Compare a fresh session sending two prompts rapidly: ordinary work, starting a
subagent, and Agent Teams if supported by the pinned CLI. Distinguish those
agent mechanisms before choosing a reproduction. Include before/after first
prompt-ready and working transitions, long/multiline input and a control with
no agent launch. Track one synthetic input identity through composer dispatch,
local queue, semantic submit, PTY write/Enter and the consumed user record.

Identify whether input is unsubmitted, legitimately queued by CLI, accepted
with a stale/missing mirror, or intercepted by a CLI blocking state. Define
pending/accepted/failed feedback and recovery without guessing from the text
currently visible in Console. A later fix must deliver each intended input
once, display truthful pending state, preserve order and avoid re-sending
already accepted text. Validate queue transitions, interruption, reconnect,
identical successive messages and isolation between tabs. Rebuild affected
shipped bundles and verify the exact Windows candidate; do not silently add
another Enter/retry or make the local queue the delivery authority.
