## Symptom and scope

At a fractional display scale, font-derived line spacing can differ from
Chromium and accumulate across wrapped lines. The original normal-line helper
rounded ascent, descent and line gap separately in CSS pixels. Baseline layout
used unrounded font extents. Native comparison confirmed the metric-coordinate
mismatch before implementation.

The bounded change concerns metric conversion, baseline placement and cache
invalidation when the display scale changes. It must preserve explicit CSS
line heights, font metric overrides and synchronous layout after mutations.
It must not select behavior by a page, family name or fixture.

## Expected outcome

Synthetic tests cover fractional scales, ascent/descent/line-gap composition,
half-leading and reuse after a scale change. Focused CSS Inline, Fonts and Text
checks pass. Engine journal timings and memory measurements assess the hot path.
The PR reports measured geometry and comparison limits without treating
different glyph smoothing as a layout defect.

## Missing evidence and blockers

Focused native comparison confirms the corrected normal line height and first
baseline, with unchanged wrapping. This does not establish exact glyph raster
equivalence or complete page geometry. The focused WPT gate, resource checks and
comparison census remain pending. No merge or release is authorized for the
executor.
