# 22 — Пиксель-точность 1:1 (ОБЯЗАТЕЛЬНОЕ требование)

**Правило проекта №0.** UI воспроизводится **1-в-1**, не «примерно/похоже». Шрифт, каждый font-size/weight/line-height, каждый padding/margin/gap, каждый радиус/бордер, каждая позиция/offset/transform, каждый размер иконки/кнопки/строки — берутся из точных значений kamin-ide (per-component CSS-модули, plan/23), а не подбираются на глаз. «Достаточно близко» = отклонение = баг.

## Почему это критично (а не педантизм)

1. **Шрифт задаёт всю метрику.** Bricolage Grotesque Variable имеет собственные пропорции, x-height, ширину глифов, tabular-nums. Любой другой шрифт (или дефолтный sans GPUI) сдвинет ширину каждой строки, высоту каждой кнопки с текстом, перенос — и весь layout «поплывёт». → Bricolage ОБЯЗАН быть вложен и применён как основной UI-шрифт; mono (JetBrains Mono, 13px) — для редактора/терминала. Размер шрифта не «≈13», а РОВНО значение токена элемента (fs-xs 11 / sm 12 / md 13 / lg 16 / xl 22 + строчные override'ы).

2. **Отступы — это структура, а не декор.** Меж-панельный gap ровно 8px + gutter 4px (`.body`), радиус панелей ровно 16px, activity-bar ровно 48px, титлбар ровно 42px, статус-бар ровно 24px. Сдвиг на 1-2px ломает выравнивание иконок с текстом, симметрию капсул, «concentric radius» (внешний=внутренний+padding). Пользователь ЗАМЕЧАЕТ рассинхрон, даже если не может назвать причину.

3. **Расположение = мышечная память.** Порядок кнопок титлбара, позиции hover-поповеров (side/offset), где всплывает контекст-меню, куда прилипает scroll — всё воспроизводится точь-в-точь, иначе «то же приложение, но чужое».

4. **Токен ≠ достаточно.** Токены (plan 20) дают палитру и шкалу. Но КАЖДЫЙ компонент применяет их своей комбинацией (напр. кнопка титлбара: 36px квадрат, padding X, icon 16px, radius 8, hover text-primary 10%). Эти комбинации — в per-component CSS, и именно они переносятся дословно (plan 23).

## Механизм гарантии 1:1 в GPUI

- **Один источник размеров.** Rust-модуль `metrics` = константы из kamin-ide (layout-tokens + constants.ts + per-component значения plan/23). Ни одного «магического» числа в компонентах — только ссылка на metrics. Изменение = правка одного места, как CSS-переменная.
- **Шрифты вложены в бинарь** (Bricolage variable ttf + JetBrains Mono + codicon + FA-solid + шрифты Phosphor-нет, SVG). Рендер текста — тем же font-size/weight/line-height.
- **Spacing-хелперы** повторяют CSS-семантику: `gap`, `padding` по сторонам, `radius` concentric-правило. GPUI px = логические px (как CSS); DPI-скейл — системный, как в браузере.
- **Визуальный дифф-тест.** На каждый экран — эталонный скрин kamin-ide и GPUI при одинаковом размере окна/теме; попиксельное сравнение (допуск = 0 по геометрии, минимальный по антиалиасингу шрифта). Экран закрыт только при совпадении. DesignPanel (plan/45 §4) — встроенный визуальный эталон токенов.
- **Оба состояния темы** (dark/light) и оба масштаба проверяются.
