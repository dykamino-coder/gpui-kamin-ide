# Адаптер инструкций для Codex

`CLAUDE.md` — единственный источник общих правил для ИИ-агентов в этом
репозитории. Перед любой работой полностью прочитать и соблюдать `CLAUDE.md`,
`CONTRIBUTING.md`, `ARCHITECTURE.md` и более вложенный `AGENTS.md`, если он есть
в затрагиваемой папке.

Все правила `CLAUDE.md` применяются к Codex, даже если имя файла или отдельная
формулировка упоминает Claude Code. Общие правила здесь не дублировать: менять
их нужно только в `CLAUDE.md`.
