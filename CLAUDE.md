# Инструкции Claude Code

Перед любой работой обязательно полностью прочитать:

1. `CONTRIBUTING.md` — единый процесс разработки, PR и релизов;
2. `ARCHITECTURE.md` — границы модулей и проверки проекта;
3. `AGENTS.md` — общие правила изоляции, version policy и качества для
   ИИ-агентов.

Правила из `AGENTS.md` применяются к Claude Code полностью, даже если клиент
не загружает этот файл автоматически. При конфликте более конкретная инструкция
пользователя имеет приоритет, но она не разрешает затрагивать чужие worktree или
выполнять release/publication без явного поручения.

По умолчанию любая задача — **change PR**:

- отдельная ветка/worktree от актуального `origin/main`;
- без повышения Cargo и Bridge server release-версий;
- без GitHub Release, merge и Docker publication;
- с применимыми проверками и честным отчётом о незапущенных проверках.

Release-операции выполняются только по прямому поручению подготовить релиз и в
порядке, заданном `CONTRIBUTING.md`.
