# KaminIDE — диагностика CPU

Собрано 2026-09-01, приложение работало и жрало CPU в момент снятия.

## Ответы на вопросы

- **Версия (первая строка diag.log):** `[boot] KaminIDE 1.0.53` — совпадает с репозиторием, ссылки на строки актуальны.
- **Что на экране в момент жора:** приложение просто открыто, чат не стримит, терминал не выводит. Жор идёт на простое.

## Ключевые цифры

### Среда — RDP, GPU нет
- `SESSIONNAME = RDP-Tcp#1`
- Видео: `Microsoft Remote Display Adapter` (CurrentRefreshRate **32**, 1920x1080) + `Microsoft Basic Display Adapter` (RefreshRate 1, 1024x768)
- Software-путь подтверждён: в diag.log есть строки `[sw]`.

### Потоки главного процесса (10 с, всего 62 потока)
Девять потоков с одним и тем же StartAddress `0x7FFCD3C7CC70` крутятся по ~6 с из 10 каждый
(7,27 / 6,92 / 6,25 / 6,11 / 6,00 / 5,97 / 5,83 / 5,73 / 5,58) — это пул воркеров, а не один горячий поток.
См. `threads.txt`.

### diag.log — хвост
Строки на простое, типичные значения:
- `[sw] кадров 120–128: копия в среднем ~1300 мкс, dirty в среднем 2–3%, интервал 7–8 мс`
- `[cef] за секунду: кадров 120–128, кадров окна 22–27, отрисовок 44–54, заказано 32–47, срочно 44–54,`
  `время кадра в среднем 666–1241 мкс, худший 838–11654 мкс; узлов на кадр 398, вью 22–27;`
  `taffy 180–224 мкс, раскладка 137–172 мкс; переиграно вью 0; шейпинг: промахов 0–1, вью всего ~858–1054`

То есть **120+ кадров/сек при неподвижном экране и монитором с частотой 32 Гц**,
и ~22–27 кадров окна в секунду при dirty-области 2–3%.
