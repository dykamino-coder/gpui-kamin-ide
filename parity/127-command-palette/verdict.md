## Цикл 35 (дополнение): MATCH

Гейт `contributes.menus.commandPalette` + `when` портирован
(`state.ts:68-76`): из снапшота реестра тянутся записи палитры и
`contextKeys`, гейт строится по правилу «команда С записями видна, только
если у ОДНОЙ из них `when` истинен (пустой = всегда); команда без записи
видна по умолчанию», клаузы считает наш полный движок `crate::when`
(порт `when-clause.ts`, он же обслуживает explorer-меню).

Контекст = ключи реестра плюс локальные, которые оригинал держит в
`localContextKeys` (`MonacoEditor.tsx:216-294`): `resourceFilename`,
`resourceExtname`, `resourceScheme`, `editorFocus` активного таба.

Покрыто юнит-тестом `gate_matches_state_ts`: запись без `when`, истинный
`when`, ложный `when`, ДВЕ записи на одну команду (хватает одной истинной)
и команда без записи вовсе.

На живом стенде гейт сейчас пустой — установленные расширения записей
`commandPalette` не приносят (проверено `rpc kamin:registry:snapshot`:
0 записей, 5 ключей контекста), поэтому в палитре по-прежнему 50 команд.
