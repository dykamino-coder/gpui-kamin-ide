# Машиночитаемый отчёт сверки

`python parity/gate.py --json` пишет `parity/REPORT.json` — снимок состояния
всех досье в форме, пригодной для CI и для внешнего чтения без парсинга
markdown.

## Контракт

```json
{
  "total": 159,
  "match": 126,
  "diverges": 33,
  "unjudged": 0,
  "no_shots": [70, 71, 90, 123, 156, 157],
  "closed": false,
  "elements": [
    {
      "id": 2,
      "slug": "titlebar-left-cluster",
      "verdict": "MATCH | DIVERGES",
      "cycle": "23",
      "shots": true,
      "open": ["…", "…"]
    }
  ]
}
```

- `closed` — единственный флаг «парити завершён»: `true`, только когда каждый
  элемент в последнем цикле получил MATCH и нет досье без вердикта.
  Код возврата гейта повторяет его (0 / 1).
- `shots` — есть пара кадров ЛИБО в досье лежит `NO_SHOT.md` с объяснением,
  почему кадр невозможен (невизуальный элемент).
- `open` — распарсенный список из блока «Осталось: …» ПОСЛЕДНЕГО цикла.

## Требование к вердиктам

У элемента со статусом DIVERGES список `open` обязан быть НЕПУСТЫМ: вердикт
должен назвать, что именно не закрыто, строкой вида

```
Осталось: пункт один; пункт два; пункт три.
```

Пустой `open` при DIVERGES — брак вердикта, а не свойство элемента: он
означает, что расхождение зафиксировано прозой и его нельзя ни посчитать, ни
отследить. Проверка:

```bash
python parity/gate.py --json
python -c "import json;r=json.load(open('parity/REPORT.json',encoding='utf-8'));print([e['id'] for e in r['elements'] if e['verdict']=='DIVERGES' and not e['open']])"
```
