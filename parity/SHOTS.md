# Поэлементные кадры: что мешает

`python parity/shots.py` снимает НАШУ сторону кропом по живым bounds из probe.
Правило одно: **один регион — один элемент**. Если на регион претендует больше
одного досье, скрипт кадр НЕ пишет: общий кроп в разных папках — ровно тот
дефект, из-за которого вердикты держались на сверке кода, а гейт считал досье
проверенным (ц.25: 14 групп; после разведения регионов — 17 групп на 105 досье).

## Текущий блок

```
НЕ снимаю (регион делят несколько элементов, нужен свой probe_area):
  file-mode-tabs: 61-file-panel-root, 64-file-panel-mode-tabs
  layout-toggles: 10-layout-toggles-trigger, 12-layout-preset-chip, 16-layout-toggles
  right-top: 56-right-panel-column, 58-right-panel-top-card
  01-titlebar: 1750×60 физ. из региона «titlebar»
  03-titlebar-brand-logo: 60×60 физ. из региона «brand»
  04-titlebar-tabs-slot: 1081×60 физ. из региона «tabs-slot»
  05-titlebar-command-search-button: 211×45 физ. из региона «command-search»
  08-titlebar-quick-actions-row: 70×50 физ. из региона «quick-actions»
  09-titlebar-quick-action-button: 50×50 физ. из региона «toggle-sidebar»
  108-file-viewer-wrapper: 496×554 физ. из региона «file-viewer-wrapper»
```

Каждой строке нужен свой `probe_area("<id>")` в порте — на корне ИМЕННО этого
элемента, а не на его контейнере. После этого строка уходит из списка и досье
получает собственный кадр.

## Порядок

1. добавить `probe_area` в код элемента;
2. `python parity/shots.py --list` — убедиться, что элемент больше не «без
   источника кадра» и не в списке выше;
3. привести окно в нужное состояние (для меню и модалок — эмит из `STATES`);
4. `python parity/shots.py`;
5. `python parity/gate.py` — метрика «общий кадр вместо поэлементного» обязана
   падать.

Оригинальную сторону (`original.png`) так снять нельзя: нужен запущенный
KaminIDE и та же покадровая проводка по состояниям.

## Разведено в ц.26

Десять досье получили СВОЙ `probe_area` вместо ссылки на контейнер:
`file-tree-folder-row`, `file-tree-file-row`, `file-tree-row-badge` (94/95/97),
`file-viewer-tab` (111), `status-item-contributed`, `status-encoding`,
`status-version` (118/119/120), `session-strip` (18),
`file-viewer-wrapper` (108), `sample-tab-strip` (146). Восемь подтверждены
живьём; `file-tree-row-badge`
рождается только когда у файла в кадре есть git-декорация — это состояние, а не
пропуск.

`115-webview-tab-icon` из карты убран совсем: иконки вебвью-таба в порте нет,
снимать нечего до подсистемы 114.

Из карты убраны как «снимать нечего»: `02-titlebar-left-cluster` (обёртки
`.leftCluster` в порте нет), `07-titlebar-button` (это рецепт кнопки, свой
кадр ему даёт 09), `06-titlebar-window-controls-cluster` и
`157-activity-drop-highlight` (состояние драга).

## Метрика стала честной (ц.26)

Гейт больше НЕ считает досье «с парой кадров», если его `ours.png` входит в
группу общих. До правки метрика показывала 6 пробелов при 92 досье на чужих
кропах — то есть врала в пятнадцать раз. Сейчас: **без пары кадров 98**, и это
настоящий размер работы.

Каждый закрытый регион снимает по единице сразу с двух счётчиков.
