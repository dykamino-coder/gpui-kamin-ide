## Цикл 35: MATCH

Все четыре остатка закрыты.

1. **F2.** У оригинала `onKeyDown` висит на САМОЙ строке
   (`SessionItem.tsx:98`), то есть переименовывается строка под фокусом; у нас
   действие было глобальным и всегда брало АКТИВНУЮ сессию. Теперь обработчик
   читает `focus_ring::focused_id()` и работает только на `srow:<id>`; фокуса
   на строке нет — F2 не делает ничего, как в оригинале. Сам нажатый F2 probe
   доставить не может (клавиши в gpui не идут), но источник — `focused_id()` —
   проверен: `probe emit focusNext` даёт `focused: frow:C:\Users%USERNAME%\.matplotlib`,
   то есть id сфокусированного элемента читается верно.
2. **Тултип абсолютного времени.** `.time` получил
   `data-tooltip={absoluteTime(...)}` (`SessionItem.tsx:110`). Заодно устранено
   дублирование: обе формы времени жили и в панели логов, и в списке сессий —
   вынесены в `ui/time_fmt.rs` (порт `utils/relative-time.ts`, где у оригинала
   они тоже лежат вместе).
3. **Кольцо фокуса.** Было `RADIUS_SM` (8) при радиусе строки
   `border-radius: var(--radius-xs)` = 4 → стало `RADIUS_XS`.
4. **Подогнанный вычет 102.4** заменён на `label_deduction(s)`, собранный из
   CSS поимённо: `padding: 0 8 0 16` + рамка 1px с двух сторон + `.dot` 4 +
   `gap` 8 + ширина строки времени + её `gap` 8 + `.pin` 20 + `gap` 8 у
   закреплённых. Ширина времени считается той же метрикой, которой режет
   `fit_approx` (новый `text_fit::approx_width`), поэтому бюджет и усечение
   больше не расходятся. Кадром проверено: «Create new docx do…» с «11h»
   справа, без наезда.
