## Цикл 24: MATCH

Якорь каскада больше не выводится из коробки меню, а берётся ИЗМЕРЕННЫМ rect
строки «Open In» — ровно как `e.currentTarget.getBoundingClientRect()`
(`FileContextMenu.tsx:76`). Замер кадра: строка x 1033.6 w 169.6 h 32 →
`sub.left = 1203.2 + 2 = 1205.2` (на 3 px внутрь правой рамки меню 1208.2),
`sub.top = 135.2 + 16 − 35.4 = 115.8` — центр по строке (`clamp-popup.ts:103`).

Флип влево — только при `row.left − 2 − 180 >= 8` (`clamp-popup.ts:92-94`);
главная ось не клампится, каскад свисает, как в оригинале.

Для проверяемости каскада (открывается лишь по ховеру, а probe-ховер до gpui
не доходит) добавлен probe-emit `fileMenuOpenIn`.
