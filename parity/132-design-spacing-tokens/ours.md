# 132 design-spacing-tokens — наша реализация

Файлы: `crates/shell/src/ui/design_panel.rs` (блок Spacing внутри
`design_panel`), значения — `crates/metrics/src/lib.rs` (`SPACE_1..SPACE_7`).

> Досье переписано в цикле 13: прежний текст описывал «горизонтальный ряд из
> семи квадратов s×s с радиусом 2 и подписями 1..7» — такого блока в коде нет
> и не было с цикла ~6 (ревью зоны 130-159).

## Структура (gpui-дерево)
```
div (flex col, gap SPACE_2)                       // .spacingList
  └ ×7 div (flex, items_center, gap SPACE_3)      // .spacingRow
      ├ token_name("--space-N", 90)               // моно FS_XS, text-secondary
      ├ token_value("Npx", 60)                    // моно FS_XS, text-muted
      └ полоса  w = токен, h 16, rounded RADIUS_XS, bg accent-primary
```

## Метрики (из кода, точные)
- Ряды: `SPACE_1..SPACE_7` = **4 / 8 / 12 / 16 / 20 / 24 / 28**; подпись
  значения — тот же список литералами.
- Колонки 90 и 60 (как `grid-template-columns: 90px 60px 1fr` оригинала),
  `gap` SPACE_3 **12**, между рядами SPACE_2 **8**.
- Полоса: высота **16**, ширина = значение токена, `rounded` RADIUS_XS **4**,
  заливка `accent_primary` СПЛОШНАЯ.

## Отличия от original.md той же папки
1. `grid 90px 60px 1fr` заменён на flex с фиксированными боксами 90/60 и
   растянутым третьим — визуально то же, но колонки не выравниваются по
   гриду при переполнении.
2. `letter-spacing` у подписей отсутствует (ограничение движка).

## Атрибуты
- отступы: между рядами 8; между колонками 12
- цвета: полоса `accent_primary` #89b4fa (светлая #d97706-ветка палитры), имя токена text-secondary #adb3c7, значение text-muted #838aa0
- шрифты: имя и значение — моно FS_XS 11
- скругления: полоса RADIUS_XS 4
- гапы: см. отступы
