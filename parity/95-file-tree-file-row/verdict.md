## Цикл 24: DIVERGES

Уточнение модели (важно, прошлые циклы описывали её неверно): у оригинала
`onDragStart → beginNativeDrag` СНАЧАЛА гасит HTML5-драг
(`e.preventDefault()`), а потом стартует НАТИВНЫЙ OS-драг Tauri
(`startDrag({item: paths, mode: "copy"})`). Внутри приложения такой драг
принимает ТОЛЬКО дерево (`fileDropTarget` используется лишь в
`FileTreeView.tsx:168`) — редактор и терминал целями не являются.
Значит наши дропы «в редактор = открыть» и «в терминал = вставить путь» —
НАША надстройка, а не порт.

Закрыто в этом цикле: набор путей драга — порт `dragPaths()`
(`file-selection.ts:67`): строка внутри мультивыбора тащит ВЕСЬ набор, иначе
только себя; призрак показывает «имя +N». Наши дропы теперь тоже работают по
набору (терминал — все пути через пробел, редактор — открыть каждый).
Мёртвое поле `DraggedFile.path` удалено.

Осталось: нативный OS-драг наружу (Explorer и прочие приложения). В gpui это
`DoDragDrop`/`IDropSource` — модальный цикл, который нельзя крутить на
render-потоке; нужен отдельный поток со своей очередью сообщений. Не начинал.

Проверка драга через probe НЕ засчитана: синтетический drag дал один файл из
двух, но причину (какая строка была под курсором в момент старта) кадром не
подтвердил — эту часть держу открытой честно, а не как «сделано».
