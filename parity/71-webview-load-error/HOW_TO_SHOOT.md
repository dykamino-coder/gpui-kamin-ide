# 71 — как снять кадр нашей стороны (пока не снят)

Состояние: карточка терминальной ошибки загрузки вебвью-панели
(`WebviewPanelView.tsx:26-31`), у нас — `webview_skeleton::load_error`.
Условие показа в порте: у вью НЕТ html И бюджет resolve исчерпан
(`tries >= 45`, `root.rs`).

Что уже сделано для съёмки:
- probe-эмит `{"cmd":"emit","kind":"viewLoadError","name":"<viewId>"}` —
  ставит `tries = 45`, чистит `pending_html` и выкидывает html вью из стора
  (`chat_webview::drop_html`).

Почему кадра всё ещё нет: при visual hosting (`wv_visual::enabled()`) панель
рисует УЖЕ ЗАПУЩЕННУЮ поверхность WebView2 — она отвязана от нашего
html-стора и продолжает показывать страницу, даже когда стор пуст. То есть
состояние достижимо только если вебвью НИКОГДА не стартовал для этого вью.

Следующий шаг (не начинал): гейт запуска вебвью на старте процесса —
переменная окружения вида `KAMIN_FORCE_VIEW_ERROR=<viewId>`, которая не даёт
`wv_visual` поднять поверхность для этого id. Тогда панель честно уходит в
ветку загрузки и карточка снимается кадром.
