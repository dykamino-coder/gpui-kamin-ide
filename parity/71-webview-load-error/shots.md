# Кадры: нет ни одного

Терминальный экран «This panel didn't load» показывается только при
исчерпании бюджета resolve вебвью. Чтобы снять обе стороны, нужен
принудительный отказ resolve: у нас — `ShellEvent::RetryView` + заглушённый
host, у оригинала — то же на стороне exthost. Отдельный сценарий, пока не
воспроизведён.
